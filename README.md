# XCTrack をハンググライダーで使うためのセットアップガイド（Android）

XCTrack は Android 専用の無料フライトインストゥルメントアプリです（iOS 版はありません）。
このガイドは、手持ちの Android スマホをハンググライダー用の計器として使えるようにするための手順をまとめたものです。

> メニュー名はアプリのバージョンや表示言語によって多少異なることがあります。

---

## 1. スマホが使えるか確認する

| 項目 | 必要度 | 確認方法 |
|---|---|---|
| GPS | 必須 | ほぼ全ての Android 端末に搭載 |
| 気圧センサー（バロメーター） | 強く推奨（バリオ・高度精度に必要） | 「Sensor Test」等のアプリ、またはメーカー仕様表で「気圧センサー」の有無を確認 |
| 画面の明るさ | 推奨 | 日差しの下で見えるか。ピーク輝度が高い端末ほど良い |
| バッテリー | 推奨 | 長時間フライトならモバイルバッテリーを併用 |

**気圧センサーが無い端末の場合：** GPS 高度だけでは昇降計（バリオ）がほぼ使えません。
Bluetooth 接続の外部バリオ（XC Tracer、BlueFly、SkyBean、Flytec 系など XCTrack 対応機）を用意し、
XCTrack の設定で外部センサーとして接続してください。

## 2. インストール

1. Google Play ストアで **「XCTrack」** を検索してインストール（開発元: XContest / Petr Chromec）。
2. 初回起動時に以下の権限を **すべて許可** します。
   - 位置情報：「アプリの使用中のみ」ではなく **「常に許可」**（画面オフ時もログを止めないため）
   - 通知（ライブトラッキングやバックグラウンド動作の表示に必要）
   - 近くのデバイス / Bluetooth（外部バリオを使う場合）

## 3. Android 側の設定（重要）

フライト中にアプリが止まるのを防ぎます。

- **バッテリー最適化を無効化**：設定 → アプリ → XCTrack → バッテリー → 「制限なし」/「最適化しない」
- 省電力モード・バッテリーセーバーは飛行中オフ
- メーカー独自の省電力機能（Xiaomi、OPPO、Huawei、Samsung の「スリープ状態のアプリ」など）から XCTrack を除外
- 位置情報の精度：「Google 位置情報の精度」をオン
- 自動回転はオフ（ハーネスやベースバーの振動で画面が回るのを防ぐ）

## 4. XCTrack の基本設定（ハンググライダー向け）

XCTrack の右上メニュー → **設定（Preferences）** から行います。

### パイロット / 機体
- **パイロット名・機体名** を入力（IGC ログに記録されます）。
- **機体（グライダー）タイプ**：ハンググライダー（HG）を選択できる場合は選択。
- **ポーラー（滑空性能）**：お使いの機体のトリムスピード・最良滑空速度・沈下率を入力。
  ハンググライダーはパラグライダーより速度域が高いので、デフォルト値のままだと
  最終滑空（ファイナルグライド）計算・必要高度が大きくずれます。
  目安（機体により異なるので必ず自分の機体の値で）:
  - 初中級機：トリム約 35 km/h、最良 L/D 約 10
  - 上級キングポスト / トップレス機：トリム約 40 km/h、最良 L/D 12〜15 以上

### バリオ（昇降計）
- 気圧センサーまたは外部バリオを選択。
- 上昇音の閾値：+0.1〜+0.2 m/s 程度から好みで調整。
- 沈下アラーム：HG は通常の滑空でも沈下が大きいので、-2.5〜-3.5 m/s 程度に設定すると誤報が減ります。
- バリオの平滑化（ダンピング）：HG は旋回半径が大きく、少し長めにすると読みやすいことがあります。

### 高度
- フライト前に **離陸場の標高で QNH / 高度を合わせる**（ランチ前に必ず）。

### 地図・空域
- **オフライン地図**をダウンロード（エリアを選んで事前に Wi-Fi で取得）。山間部は電波が無いことが多いです。
- **空域（Airspace）**：XContest の空域データを有効化し、日本のデータを読み込む。
  空域警告（水平・垂直の距離）を設定。
- **ウェイポイント**：エリアのテイクオフ・ランディング・ターンポイントを読み込み（`.wpt` / `.cup` / XContest など）。

### ライブトラッキング（任意）
- XContest アカウントでログインすると、仲間や回収担当にリアルタイムで位置を共有できます。
- 緊急時の位置共有として有効にしておくのがおすすめです。

## 5. 画面レイアウト（HG 向けおすすめ）

ハンググライダーではベースバー付近の小さめの画面を一瞬で読む必要があるので、
**ウィジェットは少なく、大きく** が基本です。

おすすめのメインページ構成:

1. **バリオ（大きく）** ＋ 平均上昇率（サーマル平均）
2. **高度**（QNH 高度）と **対地高度（AGL）**
3. **対地速度** と **風向・風速**
4. **地図**（空域・ウェイポイント表示）
5. **L/D（滑空比）** または **ファイナルグライド必要高度**

2 ページ目にサーマルアシスト（センタリング補助）、3 ページ目にタスク（大会用）を置くと便利です。
レイアウトは「設定 → レイアウト（Customize layout）」で編集し、エクスポートしておくと機種変更時も復元できます。

## 6. ハンググライダーへの取り付け

- **取り付け位置**：コントロールバーのアップライト（片側）またはベースバー中央。
  視線移動が少なく、ランディング時のフレアやバー操作の邪魔にならない位置を選びます。
- **マウント**：アップライト / ベースバー径に合うクランプ式スマホホルダー（例：RAM マウント系、Quad Lock 系）を使用。
  振動とハードランディングに耐えるものを選び、**落下防止ストラップ（ランヤード）** を必ず併用。
- **日除け / 防眩**：画面のアンチグレアフィルムがあると直射日光下でも見やすくなります。
- **保温**：冬季や高高度ではバッテリー低下が早いので、ハーネス内にモバイルバッテリーとケーブルを通しておくと安心。

## 7. フライト前チェックリスト

- [ ] バッテリー 100%（モバイルバッテリーも満充電）
- [ ] GPS を測位済み（離陸前に数分起動しておく）
- [ ] 高度（QNH）を離陸場標高に合わせた
- [ ] バリオ音が鳴ることを確認（スマホを上下に動かして確認）
- [ ] オフライン地図・空域・ウェイポイントが読み込まれている
- [ ] ライブトラッキングがオン（使う場合）
- [ ] 画面の自動スリープが無効（XCTrack の「画面を常にオン」）
- [ ] マウントの固定とランヤードを確認
- [ ] 機内モードにする場合でも GPS はオンのまま

## 8. フライト後

- IGC ログは自動保存されます。XCTrack から **XContest へ直接アップロード** できます。
- JHF の飛行記録や大会提出用には IGC ファイルを書き出して使用します。

## トラブルシューティング

| 症状 | 対処 |
|---|---|
| フライト途中でログが途切れる | バッテリー最適化・メーカー独自の省電力から XCTrack を除外。位置情報を「常に許可」に |
| バリオが反応しない / 遅い | 気圧センサーの有無を確認。無い場合は外部 Bluetooth バリオを接続。ダンピングを短く |
| 高度がずれる | 離陸前に QNH / 標高を合わせ直す |
| 画面が見づらい | 明るさ最大・ウィジェット数を減らし文字を大きく・高コントラストのテーマに |
| 最終滑空計算が合わない | ポーラーを自分の HG の値に設定し直す |
| 外部バリオがつながらない | Bluetooth と「近くのデバイス」権限を許可。XCTrack の設定でセンサーを再選択 |
